# AI Tool Usage Declaration (OPSC6312 Final PoE)

An AI assistant (Qwen for Part 1 planning drafts; Cursor for Part 2/3 implementation support) was used during this portfolio.

**How AI was used**

1. **Research and document structure (Part 1)** — summarising public app reviews and aligning the research and design documents with the rubric. All technical choices (offline-first design, stokvel mode, API on Render/MongoDB Atlas) were reviewed and rewritten in my own voice before submission.

2. **Implementation scaffolding (Part 2/3)** — generating starter Kotlin (Jetpack Compose), Node.js/Express API, Room offline sync, GitHub Actions workflow, and README sections. I verified every file against module requirements, replaced placeholders (Firebase, Google OAuth client IDs, Render URL), and tested on a physical device.

3. **Debugging** — explaining Gradle sync issues, Retrofit errors, and MongoDB Atlas network access when troubleshooting.

**What I did myself**

- Created and configured MongoDB Atlas, Render, Firebase, and GitHub repositories.
- Recorded the demonstration video with voice-over on my phone.
- Performed manual testing (invalid input, offline capture, sync, SSO, languages).
- Personalised the README, release notes, and screenshots.

**Citation**

Where AI suggested external libraries, official documentation was used as the primary reference (Android Developers, Firebase, Retrofit, Render, MongoDB Atlas). No assessment text was submitted without my review.
